# Space Bunny — 5 meme-reels «3AM dev» (batch)

Реф: Ddu8AkHBZzV (разобран 27.09). Один план 5–7 с, телефон в руке, крупный мем-текст сверху
белым жирным гротеском, ночь, тропическая терраса, диван, ноут с IDE в кадре. Без монтажа,
без смены ракурсов, без субтитров, без музыки поверх речи. Цель — Product Hunt-style
relatable мем для инди-дево / стартаперов.

Формат каждого варианта: 5–7 с видео + белый мем-текст (2 строки, читается за 4–5 с) +
пост-каптион EN с CTA. Текст — единственный носитель смысла, поэтому он должен
самодостаточно продавать продукт, без озвучки.

Общие параметры генерации (для всех 5):
- fal.ai video: wan/v2.2-5b/text-to-video или Kling 2.1 — handheld phone, 9:16, 24–30 fps
- длительность клипа 5 с (монтажом склеить до 6–7 с, если нужно)
- без звука в клипе, без брендовых логотипов в кадре (только обазательный ноут с IDE)
- грейд: тёплый 2000K, глубокие тени, лёгкая зернистость, никакого «чистого стока»

## Технические заметки

- Оверлей накладывается в том же стиле, что и meme_check.jpg: белый жирный гротеск,
  левый верхний угол, две строки, с лёгкой тенью/обводкой для читаемости на тёмном фоне.
- Клип генерировать без встроенного текста (модели рисуют мусорные буквы) — текст
  накладывать в монтаже.
- Если в кадре нужен конкретный человек — генерить безликую версию и прогонять
  face swap через fal-ai/id-v2v с референсом из facerefs/ (см. run_idv2v.py).
- Ориентир: wan 3.0 Prime 5s ≈ $0.7 за клип, 5 вариантов ≈ $3.5 генерации.
