# Референс для контент-фермы: яхты + Meta Ads (26.09.2026)

## 1. DdmoqJtANBC (cayayacht) — видео-шаблон для пересъёмки под наш лодочный проект

- URL: https://www.instagram.com/p/DdmoqJtANBC/ | 14.6 с, EN, аудио = трэп-трек (речь — только текст песни, не оффер).
- Статистика скромная (81 лайк) — важен не охват, а ФОРМАТ: он легко воспроизводится своими руками.
- План юзера: снять такое же видео, подставить свою лодку, запушить в Meta Ads.

Покадровый разбор (7 кадров, 1/2с):
1. y_01 — низкий POV с джетски, тёмно-синяя яхта сбоку, брызги, движение к носу.
2. y_02 — хендхелд с воды, чуть снизу вверх: чёрный корпус, белая надстройка.
3. y_03 — яхта слева/в центре, снято с соседней лодки, море и небо.
4. y_04 — уровень воды, движемся вдоль борта.
5. y_05 — корма слева, люди на swim platform.
6. y_06 — низкий кадр прямо по центру за кормой (симметрия, wake).
7. y_07 — яхта справа/в центре, смартфон-съёмка.

Общий язык: 9:16, хендхелд с воды/джетски, тёплый день, никаких титров и оффера — чистая аспирационная съёмка + трэп-трек.

Чеклист пересъёмки (что повторить): 7 ракурсов выше, длина 15 с, одна склейка в 2-3 с на ракурс, трендовый трек, БЕЗ текста на видео (оффер уводим в caption/CTA-плашку ads), мягкий цветокорр, стабилизация.

## 2. NH Partners (nhpartnersae) — референс Meta Ads оффера (скрин: nh_partners_ad_screenshot.jpg)

Структура оффера: бренд → категория → обещание → география → ценовой якорь → снятие рисков → CTA → условия.
Точные формулировки: "NH PARTNERS" / "TAX & ACCOUNTING" / "Complete Financial Support for UAE Businesses" / "For Just AED 11,999 Year" / "One Team. One Fixed Fee. No Hidden Costs." / "GET STARTED" / "T&C Apply".
Логика: недорогой входной пакет решает широкий набор задач; фиксированная цена + "one team" снимают страх переплат и координации подрядчиков. Состав услуг, гарантии и кейсы не раскрыты — доверие создаёт визуал.
Визуал: тёмно-зелёный фон, белый текст, неоновая рамка цены, уверенная бизнес-женщина в центре, вокруг размытые символы %, ключей, документов, недвижимости.
Прицел: владельцы МСБ, предприниматели, директора, стартапы в UAE.

Перенос на другие вертикали:
- Риелторство: "PROPERTY SALES / Complete Support for UAE Property Buyers and Owners", фикс-цена, "One Team. Transparent Pricing.", CTA "GET A QUOTE".
- Яхты (наш проект): визуал яхты и воды, оффер за сделку/чартер/год, акцент на брокерскую поддержку, а не круглосуточный сервис. Цену привязать к модели оказания услуги.
