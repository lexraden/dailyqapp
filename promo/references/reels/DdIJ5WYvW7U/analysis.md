## (1) О чём

Это демонстрация личной системы мониторинга AI-новостей, созданной с помощью Claude Code/Codex.

Автор показывает scraper, который:

1. Собирает данные с шести групп источников:
   - changelog Claude Code/Codex и Gemini;
   - GitHub Trending Repos;
   - trending skills на SkillsMP;
   - релевантные треды Reddit;
   - curated RSS feeds;
   - trending projects на Hugging Face.
2. Отбрасывает устаревшие материалы.
3. Собирает из потока короткий briefing:
   - главные новости;
   - новые инструменты и обновления;
   - trending repositories;
   - проекты и skills;
   - другие значимые события в AI.

**Главная ценность для зрителя — не сам scraper, а результат:** не тратить несколько часов в неде
