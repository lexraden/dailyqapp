## Воспроизведение

```bash
cd /opt/data/projects/dailyqapp/promo/control-room-reel
bash vo_v4_piper.sh 1.16     # VO -> voiceover_v4.wav (90.12s)
bash build_v4.sh             # сегменты + вертикальная сборка + аудио + mux
```

Пересъёмка: `venv/bin/python record_v4c.py` (нужны креды дашборда в `.pw.json`).
