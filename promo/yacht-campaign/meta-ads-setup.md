# Meta Ads — структура тестовой кампании

Контекст: яхта (продажа, модель не зафиксирована), UAE, у владельца 2 тёплых контакта. Реклама нужна, чтобы найти 3-го, 4-го… покупателя и проверить спрос.
Бюджеты ниже — **рекомендация для теста, согласовать с владельцем**. Валюта аккаунта — AED.

## 1. Objective — что выбрать

| Цель | Когда | Плюс | Минус | Решение |
|---|---|---|---|---|
| **Leads (Instant Form)** | Нет сайта, нужны контакты | Лид прямо в Meta, без лендинга | Много «мусорных» лидов, если форма лёгкая | **Основная для теста.** Форма типа «Higher intent» + квалифицирующие вопросы |
| **Engagement → Messages (WhatsApp)** | Владелец готов быстро отвечать в WhatsApp | В UAE WhatsApp — основной канал, живой диалог | Нужен человек на связи, лиды нельзя выгрузить автоматически | **Второй вариант** — если владелец отвечает в течение часа |
| Traffic | Есть лендинг с пикселем | Дёшево | Клики ≠ покупатели; для high-ticket плохо | Не для первого теста |
| Engagement (video views) | Прогрев | Дешёвые просмотры → аудитория для ретаргета | Нет лидов | Только как фоновая кампания на 30–50 AED/день, если бюджет позволяет |

**Рекомендация:** Leads (Instant Form). Если через 72 ч лиды есть, но «пустые» — переключить на WhatsApp.

## 2. Структура (ABO — бюджет на уровне ad set)

```
Campaign: YACHT_TEST_LEADS_2026-10  (Objective: Leads, ABO, Advantage campaign budget = OFF)
├── AdSet 1: UAE_Broad_28-55        → Креатив A (без текста, трэп)
├── AdSet 2: UAE_Broad_28-55        → Креатив B1 (плашки, оффер 1 «от владельца»)
└── AdSet 3: UAE_Broad_28-55        → Креатив B2 (плашки, оффер 2/3 «одна команда» / «тест-выход»)
```

Одинаковый таргетинг во всех ad set — тестируем ТОЛЬКО креатив. Одно объявление в ad set.

| Ad set | Креатив | Бюджет/день | 4 дня |
|---|---|---|---|
| 1 | A — `yacht_A_notext.mp4` + caption вар. 2 | 100 AED | 400 AED |
| 2 | B1 — `yacht_B_offer1.mp4` + caption вар. 1 | 100 AED | 400 AED |
| 3 | B2 — `yacht_B_offer2.mp4` + caption вар. 3 | 100 AED | 400 AED |
| **Итого** | | **300 AED/день** | **~1 200 AED** |

Минимум, чтобы что-то понять: 72 ч и ≥3–5 тыс. показов на ad set. Меньше 50 AED/день на ad set — данных не будет.

## 3. Таргетинг

- **Гео:** UAE → Dubai + Abu Dhabi (радиус по городу), «People living in or recently in this location». Для 2-го теста — добавить Sharjah/Ras Al Khaimah отдельно.
- **Возраст:** 28–55. Если аккаунт форсирует Advantage+ audience — возраст ставится как «suggestion»; тогда проверить в разбивке по возрасту через 72 ч и исключить 18–24.
- **Пол:** все.
- **Языки:** English, Russian, Arabic (отдельно не ограничивать, просто не сужать).
- **Интересы (Detailed targeting):**
  - Yachting: Yacht, Boating, Sailing, Luxury yacht, Motorboat, Jet ski.
  - Luxury: Luxury goods, Luxury vehicles, Private jet, Rolex / Mercedes-Benz / Porsche (как прокси дохода).
  - Real estate: Real estate investing, Luxury real estate, Property.
  - Логика: интересы объединены через OR в одной аудитории (размер ожидаемо ~0.5–1.5 млн — норм). Если Meta предлагает «Advantage detailed targeting» — оставить ВКЛ.
- **Исключения:** уже оставившие лид (custom audience по форме), сотрудники/знакомые (если есть список).
- **Special Ad Category:** не требуется (не жильё/кредиты/работа). Если объявление попадёт под «Housing» из-за интересов real estate — убрать real estate, креатив не менять.

## 4. Размещения

- Manual placements: **Instagram Reels, Facebook Reels, Instagram Stories, Facebook Stories.** 
- Выключить: Audience Network, Messenger, правая колонка, Explore grid (для первого теста).
- Формат только 9:16. Проверить превью каждого размещения: плашки не должны заходить под UI (нижние 20%, правый край).

## 5. Лид-форма / пиксель

**Instant Form (Higher intent — с экраном подтверждения):**
1. Intro: картинка = кадр 7 из рилса, заголовок = обещание из offer-copy.
2. Вопросы:
   - Что интересует? (Покупка / Чартер / Пока смотрю) — квалификация.
   - Бюджет? (варианты-вилки — **заполнить после согласования с владельцем**, не выдумывать).
   - Когда планируете? (В этом месяце / 1–3 мес / позже).
   - Имя, телефон (WhatsApp), e-mail — автозаполнение.
3. Privacy policy — ссылка обязательна (нет сайта → страница в Notion/Google Sites с политикой).
4. Completion screen: «Свяжемся в WhatsApp в течение [N] часов» + кнопка WhatsApp.

**Если есть сайт — Pixel + Conversions API, события:**
- `PageView` — все страницы.
- `ViewContent` — страница яхты/спецификации.
- `Contact` — клик по WhatsApp/телефону.
- `Lead` — отправка формы (оптимизация кампании на это событие).
- `Schedule` — запись на осмотр/тест-выход (самое ценное, ставить как второе событие-цель).

**Offline:** лиды из формы → Google Sheet (через Zapier/Make или ручная выгрузка раз в день). В таблице колонка «статус» (новый / связались / осмотр / сделка) — для реального CPL→CPA.

## 6. Метрики успеха (через 72 ч)

| Метрика | Как считать | Цель теста | Что значит, если ниже |
|---|---|---|---|
| **Thumbstop (hook rate)** | 3-sec video plays / Impressions | **> 30%** | Первые 2 с не цепляют → переснять шот 1 |
| Hold rate | ThruPlays / 3-sec plays | > 15% | Середина скучная → короче склейки |
| **CTR (link / all)** | Link clicks / Impressions | **> 1%** (all CTR > 1.5%) | Оффер/CTA слабый → другие плашки |
| CPM | — | ориентир, не цель | Сильно выше соседних ad set = аудитория/креатив дорогие |
| Lead form open → submit | Leads / Form opens | > 20% | Форма длинная/страшная → убрать вопрос |
| **CPL** | Spend / Leads | **Бенчмарка нет — зафиксировать базу на первом тесте.** Критерий: лид дешевле, чем [доля от маржи сделки — согласовать с владельцем] | — |
| Квал. лиды | Лиды со статусом «связались» и ответом «покупка» | ≥ 1 на всю кампанию за 4 дня | Реклама даёт шум → сменить objective на WhatsApp |
