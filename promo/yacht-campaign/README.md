## Быстрый запуск (кратко, детали в `checklist-launch.md`)

0. **Блокеры (решения владельца):** модель продажи (продать лодку / брокер / чартер) → выбор оффера 1/2/3; [ЦЕНА] (число, вилка или «по запросу»); канал лидов (WhatsApp + кто отвечает); согласие на показ яхты/людей.
1. Съёмка: 1 выход ~2 ч, 7 шотов × 5+ дублей (шот 1 — 10), по `shot-list.md`.
2. Монтаж CapCut: A/B-версии, трек из CapCut Commercial / Meta Sound Collection (правильные права для Ads), экспорт 1080×1920 → `yacht_A_notext.mp4`, `yacht_B_offer1.mp4`, `yacht_B_offer2.mp4`.
3. Аккаунты: Meta BM, AED, WhatsApp Business, privacy policy, пиксель (если есть сайт).
4. Кампания: Leads, ABO, 3 ad set (по креативу), UAE Dubai+Abu Dhabi, 28–55, Reels+Stories, 100 AED/день × 72 ч, Instant Form (Higher intent).
5. 72 ч: замер thumbstop/CTR/CPL по таблице в `meta-ads-setup.md`; решение по `checklist-launch.md` → `results-72h.md`.

## Открытые вопросы к владельцу (не блокируют съёмку, блокируют запуск Ads)

1. Что продаём: лодку / брокерское сопровождение / чартер?
2. Публичная цена или вилка? Или «по запросу»?
3. Что реально входит (тест-выход, документы, регистрация, капитан)?
4. Куда лиды и кто отвечает / за какое время?
5. Показывать яхту, название, людей? (фото-релизы от людей в кадре)
6. **2 тёплых контакта:** отправить готовый рилс лично (WhatsApp) ДО запуска Ads.

> Все [ЦЕНА]/[PRICE]/[БРЕНД] — плейсхолдеры, публикуются только после явного ОК владельца.
