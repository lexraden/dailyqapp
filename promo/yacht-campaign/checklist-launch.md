# Чеклист запуска с нуля

Файлы пакета: `shot-list.md` · `script.md` · `caption.md` · `offer-copy.md` · `meta-ads-setup.md`

## 0. До съёмки — решения владельца (блокеры)

- [ ] Модель: продажа лодки / брокер / чартер → выбран оффер 1, 2 или 3 (`offer-copy.md`).
- [ ] [ЦЕНА] — число, вилка или «по запросу». Без этого вариант B не монтируем.
- [ ] Канал лидов: WhatsApp-номер + кто отвечает и за сколько часов.
- [ ] Согласие показывать яхту/название/людей в рекламе.
- [ ] **2 тёплых контакта:** отправить им готовый рилс лично (WhatsApp) ДО запуска рекламы — это самый дешёвый «лид». Реклама — для поиска следующих.

## 1. Съёмка (1 выход, ~2 ч)

- [ ] Время: 9:00–10:30 или 16:00–17:30, ветер < 15 узлов (гладкая вода).
- [ ] Команда: капитан яхты, водитель джетски, оператор, 2–4 человека в кадре.
- [ ] Телефон: 4K 30 fps, Action mode, HDR выкл, сетка вкл, ≥80% батареи, ≥20 ГБ; аквачехол / шнурок на запястье; микрофибра.
- [ ] Отснять 7 шотов по `shot-list.md`, каждый 5+ дублей по 6–10 с. Шот 1 (хук) — 10 дублей.
- [ ] B-roll: нос режет воду, слоу-мо брызг (60 fps), палуба крупно, выход из марины.
- [ ] Фото-релизы от людей в кадре.
- [ ] Сразу после — скинуть всё на ноутбук/облако в оригинальном качестве (AirDrop / кабель, не через мессенджер — он жмёт).

## 2. Монтаж в CapCut (~1–2 ч)

- [ ] Новый проект 9:16, 1080×1920, 30 fps.
- [ ] Импорт → выбрать лучшие 2–2.5 с из каждого шота, порядок 1→7.
- [ ] Трек: для Ads — из CapCut Commercial / Meta Sound Collection (trap/phonk, 130–150 BPM). Beat → Auto-beat, склейки на метки.
- [ ] Стабилизация: клип → Stabilize → «Recommended» (не «Most stable» — кропает сильно).
- [ ] Цвет: Adjust (Contrast +8, Sat +10, Highlights −15, Temp +5) на первом клипе → Apply to all.
- [ ] Звук воды на −18 дБ под трек.
- [ ] **Версия A:** без текста → экспорт `yacht_A_notext.mp4`.
- [ ] **Версия B1/B2:** Text → 3 плашки по `script.md`, шрифт bold, белый + чёрная обводка, вне нижних 20% → экспорт `yacht_B_offer1.mp4`, `yacht_B_offer2.mp4`.
- [ ] Проверить орфографию на плашках (EN и RU) — вслух, по буквам.
- [ ] Экспорт: 1080p, 30 fps, битрейт высокий, 14.5–15 с. Удалить водяной знак CapCut в конце (Settings → убрать end card).
- [ ] Посмотреть на телефоне в полноэкранном режиме — текст не под UI Reels.

## 3. Подготовка аккаунтов (один раз)

- [ ] Meta Business Manager, Facebook-страница + Instagram-аккаунт привязаны.
- [ ] Рекламный аккаунт: валюта AED, часовой пояс Dubai (GMT+4), карта привязана.
- [ ] WhatsApp Business номер привязан к странице (если WhatsApp-вариант).
- [ ] Privacy policy URL для лид-формы.
- [ ] (Если сайт есть) Pixel + события `Lead`, `Contact`, `Schedule` — проверить в Events Manager → Test events.

## 4. Сборка кампании (~40 мин, по `meta-ads-setup.md`)

- [ ] Campaign: Leads, ABO (Advantage campaign budget OFF), имя `YACHT_TEST_LEADS_<дата>`.
- [ ] 3 ad set, одинаковый таргетинг: UAE (Dubai + Abu Dhabi), 28–55, интересы yachting/luxury/real estate, placements Reels + Stories (IG+FB).
- [ ] Бюджет 100 AED/день на ad set (согласовать), старт в 8:00 по Дубаю.
- [ ] Объявления: A / B1 / B2 + соответствующие caption из `caption.md` (без хэштегов). Кнопка CTA по таблице в `caption.md`.
- [ ] Instant Form (Higher intent) с квал-вопросами; бюджетные вилки — после согласования.
- [ ] Превью каждого размещения на телефоне → Publish.
- [ ] Через 1–2 ч: проверить, что объявления прошли модерацию (статус Active, не «In review / Rejected»).

## 5. Ежедневно

- [ ] Лиды → таблица (имя, телефон, ответы, статус). Связаться в течение 1 ч — лид «остывает» быстро.
- [ ] НЕ трогать бюджеты и таргетинг первые 72 ч (обучение сбрасывается).

## 6. Замер через 72 ч

Выгрузить в Ads Manager: Breakdown → по объявлению, колонки: Impressions, 3-sec plays, ThruPlays, CTR (link), CPM, Leads, CPL, Form opens.

| Проверка | Порог | Действие |
|---|---|---|
| Thumbstop (3s plays / impr.) | < 30% у всех | Переснять/заменить шот 1 (хук), остальное не трогать |
| Thumbstop | > 30% у одного | Этот креатив — победитель по хуку |
| CTR link | < 1% при thumbstop > 30% | Картинка цепляет, оффер нет → новые плашки / другой оффер |
| Лиды | 0 при CTR > 1% | Проблема в форме → упростить, проверить privacy URL |
| Лиды есть, квал. 0 | — | Добавить вопрос-фильтр в форму или перейти на WhatsApp-цель |
| Один ad set явно лучше по CPL | в 1.5+ раза | Выключить худший, победителю +20–30% бюджета, в свободный слот — новый вариант креатива |
| Всё плохо | — | Не жечь дальше: сменить хук + оффер, повторить тест 72 ч |

- [ ] Записать итог: какой креатив выиграл, CPL, сколько квал. лидов, что меняем. Сохранить в `yacht-campaign/results-72h.md`.
- [ ] Созвон с владельцем: сколько лидов дошли до осмотра. Реальная метрика — стоимость осмотра/тест-выхода, не лида.
