# DailyQApp

A simple daily quest application.

## Features

- Track daily quests
- Level up system
- Simple CLI interface

## Tech

- Python 3.8+

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python src/dailyq.py [name]
```

If name is provided, it will be used in the greeting; defaults to "Traveler".
